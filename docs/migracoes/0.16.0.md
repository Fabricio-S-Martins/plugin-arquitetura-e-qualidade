# Migração 0.16.0

Prompt para colar no Claude do projeto, com o plugin já em 0.16.0. Pré-requisito: projeto no modelo 0.14.x ou 0.15.x.

Ajustar este projeto ao que mudou no plugin arquitetura-e-qualidade 0.16.0. Regras: não alterar código, não commitar, não renomear nem mover arquivos. Mostrar a prévia (skill previa-diff) de cada lote (~5 arquivos) e só aplicar após meu "aprovado". Nunca inventar: dado que o arquivo não confirma, me perguntar.

O que mudou na 0.16.0: menos tags. A tag de tipo é só o grupo e as tags de assunto só entram onde o caminho não diz o assunto.

- Tipo (1 por nota): `backlog` ou `documentacao`. Substitui backlog/geral, backlog/modulo, backlog/tarefa, backlog/decisao, documentacao/geral, documentacao/modulo, documentacao/api, documentacao/fluxo (e as antigas `tipo/...`, `grupo/...`, `arquivo/...`).
- Geral e nota do módulo (backlog e documentação): só o tipo; sai `modulo/<m>`.
- Tarefa e decisão: tipo + `modulo/` + `fluxo/` + `status/` (sem mudança além do tipo).
- API: tipo + `modulo/`.
- Fluxo (doc): tipo + `modulo/` (todos os módulos que o fluxo toca); sai `fluxo/<f>`.
- Não alterar docs/.obsidian/graph.json. Quem usava cor por subtipo no grafo pode usar `path:tarefas`, `path:decisoes`, `path:fluxos`, `path:api`; `tag:#backlog` e `tag:#documentacao` continuam valendo.

Exemplos: `tags: [backlog, modulo/autenticacao, fluxo/autenticacao-cadastro, status/concluido]` (tarefa); `tags: [documentacao, modulo/pedidos]` (fluxo); `tags: [backlog]` (índice do módulo).

Passos:
1. Tags: em cada nota de docs/ (ignorar docs/sessoes/), trocar a tag de tipo pelo grupo do caminho (`docs/backlog/` → `backlog`; `docs/documentacao/` → `documentacao`). Nota geral ou do módulo: remover `modulo/`. Nota de fluxo: remover `fluxo/`. Manter o resto. Se a nota de fluxo ficar sem `modulo/`, propor pelo caminho. Tag antiga em lista YAML (`tipo/`, `arquivo/`) → reescrever em 1 linha `tags: [...]`. Nota sem tag de tipo → propor pelo caminho. Mudar só o frontmatter.
2. Conferir: toda nota de docs/ com exatamente 1 de `backlog`/`documentacao`; nenhuma com `backlog/`, `documentacao/`, `tipo/`, `grupo/` ou `arquivo/`; nenhuma nota geral, de módulo ou de fluxo com tag extra proibida; decisão com ≥1 `modulo/`.
3. Relatório final curto: o que foi ajustado, o que ficou pendente e as dúvidas.
