## Regras que mudaram (até 0.36.0)
Escopo de cada item: `[geral]` qualquer linguagem; `[POO]` só se o projeto usa classes; `[C#]` só se o projeto é C#. Escrever no idioma do projeto, 1 por linha.

### Para praticas.md (obrigatórias, sem marca)
- [POO] LSP: subtipos substituem o tipo base sem quebrar o comportamento esperado. Conferir: perguntar.
- [POO] DIP: depender de abstração, na direção que a arquitetura do projeto definir; injeção via construtor. Conferir: perguntar.
- [POO] Demeter: um objeto só fala com seus vizinhos diretos. Conferir: perguntar.
- [geral] 1 indentação por método. Conferir: perguntar.
- [geral] Sem else. Conferir: Grep de `\belse\b` nos arquivos de código do escopo; nenhuma ocorrência é indício de uso.
- [POO] KISS no método: método privado só com reuso real ou (complexidade isolável + conceito de domínio nomeável); senão inline. Conferir: perguntar.
- [POO] YAGNI: interface só com 2 ou mais implementações ou em fronteira de infraestrutura. Conferir: perguntar.
- [geral] DRY: extrair na 3ª duplicação. Conferir: perguntar.
- [geral] Prioridade em conflito: KISS/YAGNI > padronização > DRY > SOLID > calisthenics. Só se algum item de SOLID ou calisthenics desta lista for adotado.

### Para praticas.md (com `(preferível)`)
- [geral] Método com no máximo 15 linhas. Conferir: perguntar.
- [POO] Classe com no máximo 150 linhas e no máximo 5 atributos. Conferir: perguntar.
- [POO] OCP: aberto para extensão, fechado para modificação. Conferir: perguntar.
- [POO] ISP: interfaces pequenas e específicas. Conferir: perguntar.
- [POO] Value objects para primitivos de domínio. Conferir: perguntar.
- [POO] Coleção de primeira classe. Conferir: perguntar.
- [POO] Sem getters/setters expondo estado. Conferir: perguntar.
- [geral] Sem abreviações nos nomes. Conferir: perguntar.

### Para testes.md (só se o projeto tem testes)
- [POO] Obrigatória: o que merece teste direto fica em classe pública, nunca privado nem testado por reflection. Conferir: perguntar.
- [C#] `(preferível)` Teste xUnit com nome `Metodo_ComCenario_DeveResultado`; o segmento do meio começa com `Com`. Conferir: Grep de `\[(Fact|Theory)\]` com 2 linhas depois e olhar os nomes.

### Para convencoes.md (todas `(preferível)`, só [C#])
- Campo privado: `private readonly Tipo _camelCase`; `readonly` quando não muda após o construtor. Conferir: Grep de `private\s+(readonly\s+)?[\w<>\[\]?]+\s+[A-Za-z]\w*\s*[;=]` (campo sem `_`); `readonly` lendo o arquivo.
- Visibilidade: classe de implementação usada só no próprio assembly (DI do mesmo projeto) é `internal`, salvo motivo real. Conferir: Grep de `^\s*public\s+(sealed\s+)?class` e ver quem a usa.
- Namespace file-scoped (`namespace X;`), nunca em bloco; exceção: código gerado (Migrations). Conferir: Grep de `^namespace\s+[\w.]+\s*(\{|$)`.
- Fim de arquivo: termina direto na última `}`, sem linha em branco. Conferir: ler o fim de alguns arquivos.
- Construção: objeto de dados sem comportamento (request, response, VO simples) é `record`; tipo pequeno, imutável e em volume é `readonly struct`; classe ou método sem estado é `static`. Conferir: Grep de `\brecord\b`.
- Nomes 100% em português (arquivo, classe, pasta, projeto); exceção: tipo imposto por biblioteca ou framework. Conferir: perguntar.
