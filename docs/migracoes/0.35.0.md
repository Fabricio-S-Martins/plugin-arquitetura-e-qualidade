# Migração 0.35.0

Prompt para colar no Claude do projeto, com o plugin já em 0.35.0. Sem pré-requisito de versão.

Ajustar este projeto ao que mudou no plugin arquitetura-e-qualidade 0.35.0. Regras: não alterar código, não commitar. Listar em texto o que vai mudar, uma só vez, e só aplicar após meu "aprovado" (prévia com antes e depois só se eu aceitar ver). Nunca inventar: dado que o arquivo não confirma, me perguntar.

O que mudou na 0.35.0: os três índices de pasta (tarefas, documentação, especificações) seguem um só modelo. Título = só o nome da pasta, sem sufixo de projeto. Logo abaixo, uma frase do que a pasta guarda. Depois a seção de módulos (`## Módulos`) com uma lista `[Módulo](caminho relativo): descrição de uma linha`; o índice das tarefas deixa a tabela e passa a usar essa lista. Ordem alfabética pelo nome do módulo, sem acento nem caixa. A descrição de um módulo é a mesma frase nos três índices. Únicas diferenças permitidas: o índice das tarefas lista também módulos sem regra de negócio nem fluxo (ex.: um módulo compartilhado) e o da documentação mantém `Não documentado`. Tags continuam as do `TAGS.md`. Nomes de pasta, arquivo, tag e título de seção citados são exemplo: valem os do projeto.

Passos:
1. Localizar os três índices (Glob na pasta de cada área: tarefas, documentação, especificações; o das tarefas é o geral, não o de cada módulo). Índice ausente → listar, sem criar.
2. Para cada um, propor a reescrita no modelo novo: título só com o nome da pasta, frase de descrição, `## Módulos` como lista, módulos em ordem alfabética.
3. Descrição de cada módulo: reaproveitar a que já existe em algum índice (ordem: documentação, especificações, tarefas). Frases diferentes entre índices ou nenhuma → me perguntar; propor a mesma frase para os três.
4. Preservar as exceções (módulos só nas tarefas, `Não documentado`) e qualquer conteúdo extra que o arquivo confirme. Não renomear pasta, arquivo nem tag.
5. Linhas das tarefas existentes no índice de cada módulo não mudam.
6. Relatório: por índice, o que mudou (título, descrição, lista, ordem, descrições reaproveitadas ou perguntadas) e o que foi preservado.
